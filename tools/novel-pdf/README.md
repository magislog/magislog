# 縦組み入稿PDFメーカー（rakunovel-kai）

小説の縦書きテキストを、**源暎こぶり明朝で入稿用PDF**にするブラウザツール。
本家 RakuNovel（らくのーべる）の要望を取り込みつつ、**透かしなし・無料・本当の1クリックPDFダウンロード**にしたブラッシュアップ版。

## できること
- 判型プリセット：**A5二段組み / 文庫(A6) / A5一段 / 新書 / B6**（数値は全部その場で編集可）
- **塗り足し 0 / 3 / 5mm**（A5+3mm＝154×216mmのPDFを自動計算）
- **フォント5種**：源暎こぶり明朝／しっぽり明朝／源暎ちくご明朝／源暎アンチック(漫画風)／源暎エムゴ(ゴシック)。全てSIL OFL 1.1・埋め込み/商用同人OK・**選んだ時だけ読込**
- 縦書きリアルタイムプレビュー（プレビュー＝出力PDFが一致）
- 自動整形：`！？→⁉`、2桁数字の**縦中横**、**禁則処理**（追い出し・ぶら下げ）
- **青空文庫ルビ**（`｜漢字《かんじ》` / `漢字《かんじ》`）・**縦中横**（2桁数字）
- **章・目次**：本文の `[章:タイトル]` で改ページ＋見出し、`[改ページ]` で改ページ、章から**目次ページを自動生成**
- **奥付**（タイトル/著者/発行日/サークル/印刷所/連絡先）を最終ページに
- **マイプリセット**：今の設定に名前を付けて保存・呼び出し（印刷所ごとの数値を作り置き）
- **背幅の自動計算**：総ページ×用紙厚 → 表紙用の背幅mmを表示
- **見開きプレビュー**／**グリフ欠け警告**（フォントに無い字を事前検知＝豆腐防止）
- **面付け自動調整**（白紙で偶数/4の倍数に）・**中扉**`[中扉:]`・**空白**`[空白]`・**トンボ**
- **.txt読込**（ドロップ）・**プロジェクト保存/読込**（設定＋本文をファイルへ）
- 分離禁則(`——`/`……`)・段落の自動字下げ・ぶら下げON/OFF
- ノンブル（ページ番号）、自動保存（ブラウザ内）
- **1クリックでPDFダウンロード**（HarfBuzzで使う字だけにサブセット＝1冊でも100KB前後）

## 起動のしかた
`起動.bat` をダブルクリック → ブラウザで `http://localhost:8793/` が開きます。
（フォントとwasmをブラウザが読むため、ファイルを直接開くのではなく簡易サーバ経由で動かします）

## 設計：機械と交換パーツを分けています
- **機械（`js/engine/`）** … 使い回す本体。
  - `typeset.js` 縦組みグリッド組版の心臓（テキスト＋設定→ページ配置モデル）
  - `render-canvas.js` プレビュー描画 / `render-pdf.js` PDF出力（同じ配置モデルを描く＝WYSIWYG）
  - `vglyph.js` 縦書き字形（回転・約物の右上寄せ）/ `kinsoku.js` 禁則 / `preprocess.js` 記号整形
  - `subset.js` HarfBuzz(wasm)でフォントを使う字だけにサブセット
  - `units.js` mm/pt/px変換
- **交換パーツ** … 差し替えて増やす部分。
  - `js/presets.js` 判型プリセット（増やすなら表に1行足すだけ）
  - `js/fonts.js` + `fonts/` フォント（増やすなら表に1行＋ttfを置くだけ）

## フォントを足したいとき
1. `fonts/` にttfを置く
2. `js/fonts.js` の `FONTS` に1行足す（`{ family:'表示名', label:'…', url:'fonts/….ttf' }`）
以上。エンジン側は無改修。
